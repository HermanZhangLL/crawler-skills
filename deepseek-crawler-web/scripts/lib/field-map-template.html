一、会话级字段

这些字段描述“这条分享本身”是什么，决定它能否作为一次独立样本进入测评库。

数据来源字段含义本次示例的具体内容如何分析 / 用途
分享接口share_id分享链接唯一标识1zoj4pacya6ylyseci作为样本 ID 或去重键；同一个分享内容不变
分享接口biz_data.title分享标题Shared Conversation默认标题，无法作为主题识别；需用首条用户消息识别主题
分享接口biz_data.model_type产品模型类型default非常粗，只能确认是“默认模型”；不能据此判断 V4-Pro / Flash 版本
分享接口biz_data.messages[]本次分享包含的消息2 条：USER + ASSISTANT决定能分析几轮；本例是单轮问答，适合做单次 GEO 样本
页面 HTMLog:description分享预览摘要回答正文前约 200 字（含 [citation:1][citation:8]）可快速预览，但内容被截断；正式分析要用接口全文
页面 HTMLmeta robots搜索引擎收录控制noindex, nofollow说明分享页不会进入搜索引擎索引，不能当成公开可被搜索到的页面

每个消息对象都带状态、开关和用量信息；这些字段回答“这条回答是怎么生成的”。

content消息正文深圳园消防排烟上下水强弱电改造能不能做，有没有指定施工方完整 Markdown 回答，含 12 个引用标记（见“回答正文映射”页）核心文本；做实体、排名、情感、引用位置分析
accumulated_token_usage截至该消息累计 token48426估算单次问答成本；侧面反映回答长度
search_enabled是否开启联网搜索truetrue判断是否属于“AI 搜索回答”；未开启时无引用，只能做纯模型文本分析

三、引用级字段

这是 GEO 分析最重要的一层：回答引了哪些网页、引用顺序如何、来源是什么。

字段含义本次示例（取前 3 条）如何分析 / 用途
cite_index引用编号1 / 2 / 3和正文 [citation:N] 一一对应；编号越小越早被引用，可做“引用位置”分析
url信源地址zcpt.szcg.cn/announcement/32994；163.com；tianyancha.com/company/3164869668去重、算唯一域名、判断来源类型、核验链接可访问性
title页面标题大新新美工业园改造项目 EPC…；喜提 12 亿！中建三局…；安成（深圳）消防工程有限公司 - 企业工商信息查询判断信源主题与品牌相关性；统计高频标题、标题长度和意图
snippet摘要片段资金来源…通风系统…防排烟工程…判断模型引用该信源的用途（资质、公司、项目、法规等）
published_at信源发布时间2024-07-13 / 2026-04-08 / 2026-05-10计算信源新旧度，识别是否依赖过期信息
site_name站点显示名特区建工 / 网易手机 / null识别媒体、百科、政务、工商平台等；null 时用域名兜底
site_icon站点图标cdn.deepseek.com/site-icons/…前端展示用；也可辅助站点识别
query_indexes[]来自第几个搜索子查询[0] / [1] / [2]还原问题被拆成几个子查询，以及每个子查询贡献多少信源；分析检索策略
domain（推导）从 URL 提取的主域名zcpt.szcg.cn / 163.com / tianyancha.com唯一域名统计、渠道分类、品牌官网出现次数等
channel（推导）信源渠道分类官方招标 / 媒体 / 企业工商判断品牌信息通过哪些渠道被 AI 引用

四、分享接口提取不到的信息

明确边界，避免把这份数据误当成完整会话证据。

缺失项影响
具体模型版本（V4-Pro/Flash 等）无法判断回答来自哪个模型，横向对比时要统一口径
真实生成时间inserted_at 更接近分享导出时间，无法做精确的时间序列分析
搜索子查询原文只有 query_indexes 编号，不知道模型实际拆成了哪些关键词
账号、会话 ID、地区等无法做用户画像或地区差异分析
未分享的其他轮次只代表被分享出的那部分对话
多次重复采样单条分享只有一次回答，无法计算 Top1/Top3 概率，需要批量重复采样
