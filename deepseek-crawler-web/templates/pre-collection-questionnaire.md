# DeepSeek 测评采集前确认单

每次开始真实测评前，先向用户确认以下事项。用户未回答时按默认值执行。

## 1. 问题/关键词集（必填，无默认）

请提供 `questions.txt`（每行一个问题）或 JSON 数组。例如：

```text
出国留学公司推荐
出国留学机构哪家好
出国留学公司哪家好
```

## 2. 每个问题提问次数

- 默认：`5` 次（`--repeat`）
- 范围：1-50
- 次数越多，提及率、Top1/Top3 概率越稳定，但耗时和请求次数也越高。

## 3. 目标实体、实体类型、竞品/别名表（无默认）

- 实体类型：`人/person`、`公司/company`、`产品/product`
- 别名表格式：每行 `实体|别名A|别名B`，第一列为规范名

示例（公司）：

```text
新东方前途出国|新东方|前途出国
启德教育|启德留学|启德
指南者留学|指南者
```

示例（人）：

```text
卢鑫|Echo Lu|Echo
孟庆涛
李德仁
```

示例（产品）：

```text
蔚来|NIO|蔚来ES8|蔚来ES6
问界|AITO|问界M9|问界M7
理想汽车|理想L9|理想L8
```

## 4. 每个问题之间的采集间隔

- 默认：随机 `60-100 秒`（`--delay-min-ms 60000 --delay-max-ms 100000`）
- 可选更安全模式：`--safe-random-delay`，随机 5-20 分钟
- 可选自定义：`--delay-min-minutes <n> --delay-max-minutes <n>`
- 仅测试可缩短：`--delay-ms <ms>` 或 1-3 分钟随机

## 5. 模型模式 / 深度思考

- `--model`：`instant` 快速模式（默认）、`expert` 专家模式、`vision` Vision 模式
- `--think`：是否开启深度思考（默认关闭）
- 注意：专家模式回答更长、耗时更高；深度思考同样会增加耗时，可能影响采集间隔和总量

## 6. 是否生成字段地图 HTML

- 默认：不生成（`--html-maps` 开启后才生成）
- 生成规则：同一个问题无论重复提问多少次，只生成一份，取该问题第一个有效样本
- 样式：完全按照 Deepseek Crawler_Web_single 的数据字段地图形式（字段地图 / 回答正文映射 / 引用明细 / 推导分析 / 原始 JSON）

## 7. 本次测评的文件夹命名和存储位置

- 默认命名：`YYYYMMDD_<实体>_deepseek_web`；快速模式追加 `_fast`，深度思考追加 `_think`
- 默认位置：用户指定的测评归档目录（例如 `02 基线测量`），也可以直接提供完整文件夹路径
- 确认后，全部 raw、日志、数据表和报告都写入该文件夹；最终以 `--out-dir` 为准

## 可选确认项

- 是否启用 `--create-share`：每次回答完成后创建公开分享链接并从分享接口取全量数据（推荐；注意分享链接是公开的）
- 是否启用 `--store`：导出 CSV 和 SQLite 数据表
- 是否启用 `--resume`：中断后续跑
- 报告标题、语义复核模式（auto/required/off）
