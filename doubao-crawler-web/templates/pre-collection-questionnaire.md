# 豆包 Web 测评采集前确认单

每次开始真实测评前，请逐项填写；不填的项按默认值执行。

## 1. 问题集（必填，无默认值）

- 文件路径：`questions.txt`（每行一个）或 JSON 数组，也可以直接粘贴。
- 每行一个问题，例如：

```text
保定市区买小高层，推荐个新交付或即将交付的小区
保定即将交付的小高层楼盘有哪些
```

## 2. 每个问题提问次数

- 默认：`1`（`--repeat 1`）
- 范围：1-50
- 填写：

## 3. 目标实体、实体类型、竞品/别名表

- 目标实体：
- 实体类型：`人/person`、`公司/company`、`产品/product`
- 别名/竞品表（每行 `规范名|别名A|别名B`，第一列为规范名）：

```text
目标实体|目标别名A|目标别名B
竞品A|竞品A别名
```

- 未填写竞品/别名：分析阶段自动从回答中推断同类型竞品（启发式）。

## 4. 题间采集间隔

- 默认：随机 `60-100 秒`（`--delay-min-ms 60000 --delay-max-ms 100000`）
- 可选：`--safe-random-delay`（5-20 分钟随机）、自定义区间、测试用 `--delay-ms`
- 填写：

## 5. 采集模式

- 默认：`快速`（quick）
- 可选：`专家`（expert）、`工作任务 Turbo`（work-turbo）、`工作任务 Pro`（work-pro）
- 豆包网页端没有 Vision 模式和独立的深度思考开关
- 填写：

## 6. 是否创建公开分享链接

- 默认：创建（`--create-share` 默认开启）
- 关闭：`--no-create-share`
- 填写：

## 7. 是否导出数据表和"问题→分享链接" Excel

- 默认：导出（CSV 始终导出；`share-links.xlsx` 默认生成，`--no-excel` 跳过）
- 填写：

## 8. 是否生成每个问题的数据字段地图

- 默认：生成（每问题一份 `field-maps/<question_id>-data-map.html`；`--no-field-maps` 跳过）
- 填写：

## 9. 浏览器采集 profile

- 默认：使用当前已登录的采集 profile
- 填写：

## 10. 输出目录

- 默认：自动生成 `runs/<时间戳>`；已有旧测评目录会自动升级为 `-v2` 等版本目录
- 填写：

## 质量约束

- 一次只跑一个任务，固定同一账号。
- 分享链接创建失败或取不到数据 -> 样本标记失败。
- 不覆盖旧版本。
