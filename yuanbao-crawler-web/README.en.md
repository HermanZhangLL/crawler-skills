# yuanbao-crawler-web

`yuanbao-crawler-web` turns repeated 腾讯元宝 web AI-search samples into GEO probability evidence. It uses a local OpenCLI Browser Bridge and an already logged-in 腾讯元宝 web session, preserves raw evidence, and generates structured Markdown, Excel, and Kami-styled HTML diagnostic reports.

## What It Does

- Asks each sample in a fresh conversation to avoid context carry-over
- Internet search on by default; supports quick mode and deep thinking (`--think`)
- Preserves raw answers, visible sources, conversation URLs, and per-sample logs
- Reports mention rate, Top 1 / Top 3 / Top 5 probability, average mentions, sentiment, source and title structure
- Compares the target against same-type competitors (person, company, product)
- Delivers JSON, Markdown, Excel, and HTML

## Requirements

- Node.js 21+ for fresh crawling (18+ for analysis-only)
- Python 3.10+
- OpenCLI CLI 1.8.6+ with the bundled `yuanbao` site adapter
- OpenCLI Browser Bridge connected to a Chrome or Edge profile
- Logged-in 腾讯元宝 web session

## Quick Start

### 1. Prepare questions

`questions.txt`, one question per line, or a JSON array of objects with optional per-question `repeat` and `target`.

### 2. Preflight

```bash
node scripts/preflight.mjs --profile <opencli-profile>
```

### 3. Batch crawl

```bash
node scripts/yuanbao_batch_crawl.mjs \
  --questions questions.txt \
  --repeat 5 \
  --profile <opencli-profile> \
  --target-entity "新东方" \
  --target-aliases "新东方前途出国,前途出国" \
  --entity-type company \
  --safe-random-delay \
  --out-dir runs/my-yuanbao-run
```

Default delay is a random 60-100 seconds between fresh conversations; use `--safe-random-delay` for a 5-20 minute random interval. Add `--think` for deep thinking, `--resume` to continue an interrupted run, and `--dry-run` to preview the plan without opening 腾讯元宝. After each answer the crawler auto-creates the public share link (share API first, UI click fallback), exports CSV/SQLite plus a question-to-share-link Excel by default, and supports `--model quick|expert|vision`, and parses the full share page by default; use `--no-create-share` to disable.

Outputs:

```text
runs/my-yuanbao-run/yuanbao-crawl.json
runs/my-yuanbao-run/raw/*.json
runs/my-yuanbao-run/logs/*.log
runs/my-yuanbao-run/batch.log
runs/my-yuanbao-run/field-maps/<question_id>-data-map.html
```

Per-question field map HTML is generated by default from the first valid sample of each question; use `--no-field-maps` to skip.

### 3.5 Public Share Link Collection (No Login)

If you already have Yuanbao share links (`https://yb.tencent.com/s/<shareId>`), parse them in batch without a browser:

```bash
node scripts/yuanbao_share_batch.mjs \
  --links share_links.txt \
  --target-entity "新东方" \
  --entity-type company \
  --out-dir runs/my-yuanbao-shares
```

Each share link becomes one sample (`transport: yuanbao-share-public`) and per-question field maps are generated by default. The public share page embeds `__NEXT_DATA__` with the question, answer text, references, media, model, and timestamps.

### 4. Generate the report

```bash
python3 scripts/analyze_yuanbao_results.py \
  runs/my-yuanbao-run/yuanbao-crawl.json \
  --target-entity "新东方" \
  --entity-type company \
  --brands-file brands.txt \
  --semantic-review auto \
  --out-dir runs/my-yuanbao-run/report
```

Outputs include `summary.json`, `structured-data.md`, `structured-data.xlsx`, `report.html`, and an optional `semantic-review-cache.json`.

## Boundaries

- Low-frequency collection of visible 腾讯元宝 web output only; no login, CAPTCHA, throttling, or risk-control bypass
- Auto share creation is the default flow; if the page structure changes and share creation fails, direct samples may have zero references, and manual public share links can be used instead
- References prefer verified browser DOM citation links and fall back to links in the answer text; missing fields reflect platform visibility limits
- Probability metrics are repeated-sample estimates, not official rankings or market share
